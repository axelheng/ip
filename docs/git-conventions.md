# Git conventions

This project follows the [SE Education Git conventions](https://se-education.org/guides/conventions/git.html).

## Commit subjects

- Use a clear subject for every commit.
- Use the imperative mood: `Add README.md`, not `Added README.md`.
- Capitalize the first letter.
- Do not end the subject with a period.
- Aim for 50 characters or fewer; never exceed 72 characters.
- Add a scope or category when it improves clarity, for example `Parser: Handle empty input`.

## Commit bodies

Nontrivial commits should include a body separated from the subject by a blank line. Explain why the change was made and include relevant context. Wrap body lines at 72 characters and use blank lines to separate paragraphs.

Do not commit or push changes unless the user explicitly asks for it.
